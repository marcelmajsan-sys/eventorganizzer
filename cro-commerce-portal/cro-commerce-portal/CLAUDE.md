Ovdje je nekad stajala druga kopija. Razišla se s originalom i počela iznositi netočne tvrdnje
(stari nazivi pozornica, stara deploy adresa, popis migracija koji staje na 024), pa je spojena
u root verziju — ništa nije izgubljeno.

Root `CLAUDE.md` se učitava automatski i kad radiš iz ovog direktorija, jer Claude Code čita
sve `CLAUDE.md` datoteke od trenutnog direktorija prema gore. Ne treba ti kopija ovdje.

> **Za razliku od dokumentacije, kod SE duplicira**: `src/` (root, Vercel deploya odatle) i
> `cro-commerce-portal/cro-commerce-portal/src/` (lokalni dev). Nakon promjene u dev direktoriju
> obavezno kopiraj u root `src/` prije commita.

Povijest svake ranije verzije dokumentacije je u gitu (`git log -- CLAUDE.md`).
